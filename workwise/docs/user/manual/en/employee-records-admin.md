#**Organization Setup**#

## **Company** ##


**a.** To set **Company**, select **Company** from Organization.

![](/docs/assets/img/hrp/organization.png)

**b.** From Company, click **New**.

![](\docs\assets\img\employee_records\compsave.png)

**c.** Upon click, below window will appear.


![](\docs\assets\img\employee_records\company02.png)
![](\docs\assets\img\employee_records\company002.png)


**d.** To set Company, you need to setup the following:


![](\docs\assets\img\employee_records\company_setup01.png)
![](\docs\assets\img\employee_records\company_setup001.png)

1. **Company Name** - enter name of company.
2. **Company Abbreviation** - enter the company abbreviation.
3. **Company TAX ID** - enter the company TAX number.
4. **Phil Health ID** - enter the company Philhealth number.
5. **SSS ID** - enter the company SSS number.
6. **Pag-Ibig ID** - enter the company Pag-ibig number.
7. **RDO Code** - enter the company RDO code.
8. **Line of Business** - enter the line of business.
9. **Bank** - enter bank name.
10. **Phone** - enter the company phone number.
11. **Company Logo** - attach the company logo.
12. **Fax** - enter the company fax number.
13. **Email** - enter the company email address.
14. **Website** - enter the company website.
15. **Default Letter Head** - select default letter head.
16. **Default Currency** - enter the default currency.

**e.** Upon completion of data, click **Save** to save the Company.

#**Employee Information Setup**#

## **Employee** ##


**a.** To create **Employee**, select **Employee** from Employee Info.

![](\docs\assets\img\employee_info\employee.png)

**b.** From Employee, click **New**.

![](\docs\assets\img\employee_info\employeenew.png)

**c.** Upon click, below window will appear.

![](\docs\assets\img\employee_info\newemployee.png)


**d.** To create new Employee 201, you need to setup the following:

**General Info**

![](\docs\assets\img\employee_info\employeesetup.png)

1. **Last Name** - enter the last name of employee.
2. **Profile Picture** - attach the picture of the employee. (If there's any)
3. **First Name** - enter the first name of employee.
4. **Middle Name** - enter the middle name of employee.
5. **Birthday** - enter the birth of date of the employee.
6. **Gender** - select the gender.
7. **Employee ID** - enter the Employee ID number.
8. **Suffix** - enter suffix of the employee.
9. **Biometrics ID** - enter the biometrics ID
10. **Maiden Name** - enter maiden name. )
11. **Email** - enter the email address.
12. **Role** - select a role for the employee. (If there's any)
13. **User ID** - enter User ID.

**Employment Info**

![](\docs\assets\img\employee_info\employeesetup01.png)

14. **Company** - select the company.
15. **Location** - select the location.
16. **Employment Status** - select the status of employment.
17. **Job Offer** - select Job offer.
18. **Position Title** - select a position title.
19. **Date Hired** - enter the date hired.
20. **Job Level** - enter job level.
21. **End of Contract** - enter end of contract. (For Contractual and Probationary)
22. **Sensitivity Level** - select sensitivity level.
23. **Is Active** - tick box if the employee is active. 
24. **Reports To** - select
25. **Department** - select the department.
 

**Salary Settings**

![](\docs\assets\img\employee_info\salarysetup.png)

1. **Total Year days** - enter total year days of the company.
2. **Rate Type** - select rate type.
3. **Rate** - enter the rate of the employee.
4. **Payroll Schedule** - select a payroll schedule.
5. **Minimum Take Home** - enter the minimum take home of the employee.
6. **Cost Center** - select a cost center.
7. **No. Hours** - enter the number of hours.
8. **Attendance Base** - tick box if it the salary is attendance base.
9. **On Hold** - tick box if the salary is on hold.
10. **Ignore Late** - tick box if the late will ignore by the system and will not count as deduction.

**Government Settings**
![](\docs\assets\img\employee_info\govsetup.png)

1. **SSS Number** - enter the SSS number.
2. **SSS Mode** - select "Manual" if it is manually deducted or "Table" if it is deducted using the SSS Contribution table. 
3. **SSS Manual** - enter the monthly contribution.
4. **SSS Frequency** - select type of frequency of the deduction.
5. **HDMF Number** - enter the HDMF number.
6. **HDMF Mode** - select "Manual" if it is manually deducted or "Table" if the  deduction is using the SSS Contribution table.
7. **HDMF Manual** - enter the monthly contribution.
8. **HDMF Frequency** - select type of frequency of deduction.
9. **PHIC Number** - enter the PHIC number.
10. **PHIC Mode** - select "Manual" if it is manually deducted or "Table" if it is deducted using the PHIC table.
11. **PHIC Manual** - enter the monthly contribution.
12. **PHIC Frequency** - select type of frequency of the deduction.
13. **TIN** - enter the Tax Identification Number.
14. **WHTAX Mode** - select "Manual" if it is manually deducted or "Table" if it is deducted using the WHTAX table.
15. **WHTAX Manual** - enter the value of WHTAX of the employee.
16. **WHTAX Frequency** - select type of frequency of the deduction.
17. **RDO Code** - enter the RDO code.

**Note: If the type of Mode is *Manual* make sure that the field of *Manual* has value.**

**e.** Upon completion of data, click **Save** to save the Employee.
