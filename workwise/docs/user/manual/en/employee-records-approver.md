### **Batch Approval** ###


**a.** To approve Applications using Batch Approval, select **Batch Approval** from Tools.

![](\docs\assets\img\hr_admin\ba.png)

**b.** Upon click of **Batch Approval**, below window will appear:

![](\docs\assets\img\hr_admin\ba1.png)

**c.** To approve new Applications, click **New**.

![](\docs\assets\img\hr_admin\new.png)

**d.** Upon click below window will appear:

![](\docs\assets\img\hr_admin\ba2.png)

**e.** To approve applications using batch approval you need to setup the following:

![](\docs\assets\img\hr_admin\ba3.png)

1. **Company** - select a company.
2. **Application Type** - select a type of application that you need to approve.
3. **Posting Date** - enter the date of posting.
4. **Employee** - select a specific employee that you need to approve the application. (optional)
5. **From Date** - enter the starting date of the application.
6. **To Date** - enter the end date of the application.


**f.** Upon completion of data, click **Save** to submit the application.

![](\docs\assets\img\hr_admin\ba5.png)
