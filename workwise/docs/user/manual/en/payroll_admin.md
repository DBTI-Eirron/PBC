## Payroll Year ##

 
**a.** To set **Payroll Year**, select **Payroll Year** from Payroll Setup.

![](docs\assets\img\payroll\payroll_year.png)

**b.** From Payroll Year, click **New**.

![](docs\assets\img\payroll\payroll_year1.png)

**c.** Upon click, below window will appear.

![](docs\assets\img\payroll\payrollyear_save.png)

**d.** To create Payroll Year, you need to setup the following:

![](docs\assets\img\payroll\payrollyear_save1.png)

1. **Year** - enter payroll year.
2. **From** - enter starting date of year.
3. **To Date** - enter end date of year.
4. **Disabled** - tick box if you want to disable the payroll year.

**e.** Upon completion of data, click **Save** to save the Payroll Year.

![](docs\assets\img\payroll\payroll_yearsave.png)



## Payroll Period ##

 
**a.** To set **Payroll Period**, select **Payroll Period** from Payroll Setup.

![](docs\assets\img\payroll\payroll_period.png)

**b.** From Payroll Period, click **New**.

![](docs\assets\img\payroll\payroll_period1.png)

**c.** Upon click, below window will appear.

![](docs\assets\img\payroll\payroll_save.png)

**d.** To create Payroll Period, you need to setup the following:

![](docs\assets\img\payroll\payroll_period2.png)

1. **Company** - select the company.
2. **Payroll Schedule** - select type of payroll schedule.
3. **Payroll Date** - enter the payroll date.
4. **Frequency** - select the frequency type.
5. **Payroll Year** - select payroll year.
6. **Last Cutoff Date of Approval** - enter the last cutoff date of approval.
7. **From** - enter the start date of payroll period.
8. **To** - enter the end date of payroll period.
9. **Attendance from Date** - enter the start date of attendance to be process.
10. **Attendance To Date** - enter the end date of attendance to be process.
11. **Status** - select the status of the payroll period. The default status is **Open**. If it is **Close** the payroll period will not appear in any transactions.

**e.** Upon completion of data, click **Save** to save the Payroll Period.

![](docs\assets\img\payroll\payroll_periodsave.png)



## Transaction Type ##

 
**a.** To set **Transaction Type**, select **Transaction Type** from Payroll Setup.

![](docs\assets\img\payroll\transaction_type.png)

![](docs\assets\img\payroll\transaction_typenew.png)

**c.** Upon click, below window will appear.

![](docs\assets\img\payroll\transaction1.png)

**d.** To create Transaction Type, you need to setup the following:

![](docs\assets\img\payroll\transaction_setup.png)


1. **Code** - enter the code that you want for the transaction type.
2. **Title** - enter the title name for the transaction type.
3. **Type** - select the type for the transaction.
4. **Entry Type** - select the type of entry.
5. **Debit Account** - select the type of debit account.
6. **Credit Account** - select the type of credit account.
7. **BIR2316 Type** - select type of BIR2316.
8. **Alphalist Consideration** - select the type of alphalist.
9. **Is Taxable** - tick box if Is Taxable.
10. **Is Bonus** - tick box if Is Bonus.
11. **Is Included in Gov't deductions** - tick box if Included in government deductions.
12. **Is Active** - tick box if Is Active.
13. **Is Recurring** - tick box if Is Recurring.
14. **Is Batch Entry** - tick box if Is Batch entry.
15. **Is Standard** - tick box if Is Standard.
16. **Payroll Register Sort Order** - enter the payroll register sort order.

**e.** Upon completion of data, click **Save** to save the Transaction Type.

![](docs\assets\img\payroll\transaction_save.png)

## Recurring Entry ##

 
**a.** To create **Recurring Entry**, select **Recurring Entry** from Payroll Processing.

![](docs\assets\img\payroll\recurring.png)

**b.** From Recurring Entry, click **New**.

![](docs\assets\img\payroll\recurring1.png)

**c.** Upon click, below window will appear.

![](docs\assets\img\payroll\recurring3.png)


**d.** To create Recurring Entry, you need to setup the following:

![](docs\assets\img\payroll\recurring4.png)

1. **Entry Type** - select type of entry for recurring application.
2. **Company** - select company.
3. **Recurring Type** - select type of recurring. 
4. **Frequency** - select frequency type of recurring entry.
5. **Status** - select a status for recurring entry. 
6. **Remarks** - enter a remarks/comments for the recurring entry.
7. **Rate** - enter a rate for the type of recurring entry.
8. **Method** - select the type of method for the recurring entry.
9. **Filter Type** - select the type of filter.
10. **Filter Value** - select a filter value for the selected filter type.
11. **Add** - click add, to add the filter value.
12. **Add Company** - click add company, to add all the employees from the company that you select. 
13. ***Child Table*** - will appear the employee's name and the amount of rate when you click the **Add** or **Add Company**.
14. **Reset Filters** - click reset filters to reset the filters/content of the child table.

**e.** Upon completion of data, click **Save** to save the Recurring Entry.

![](docs\assets\img\payroll\recurring5_001.png)
