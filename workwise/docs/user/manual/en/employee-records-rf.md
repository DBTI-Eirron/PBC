## **Applications** ##

### **Leave Application** ###


**a.** To create Leave Application, select **Leave Application** from Applications.

![](\docs\assets\img\employee_per_user\leave.png)


**b.** To add new, click **New**.

![](\docs\assets\img\employee_per_user\new.png)

**c.** To create new Application, you need to set up the following:

![](\docs\assets\img\employee_per_user\create.png)


1. **Employee** - select employee.
2. **Leave type** - select particular leave type.
3. **Posting Date** - select the posting date/the filing date.
4. **From Date** - enter the starting date of the application.
5. **To Date** - enter the end date of the application.
6. **Total Leave Days** - automated based on Application's From and To Date.
7. **Current Leave Balance** - automated based on balance on Leave Balance Setup.
8. **Medical Certificate** - this attachment will be mandated on Sick Leave base on the Timekeeping Settings.
9. **Reason** - enter the Reason of filing leave.
10. **Workflow State** - Current status of the Application.
11. **Owner** - the one who create the Application. (automated)

**d.** For Half Day Leave Setup, select the arrow down on child table,

![](\docs\assets\img\employee_per_user\child1.png)
![](\docs\assets\img\employee_per_user\child2.png)

- **Type**
 1. **Whole Day** - tick box if leave is on whole day.
 2. **2nd Half** - tick box if leave is on 2nd half.
 3. **1st Half** - tick box if leave is on 1st half.
 4. **Exclude** - tick box if you want to exclude the particular date. 

- **Holiday** - automatically tick box based on Holiday Setup.


**e.** Upon creation of the Application below More Information will appear:

![](\docs\assets\img\employee_per_user\info.png)


1. **Is LWOP** - automatically tick box once the Leave Type is leave without pay.
2. **Is Blanket** - automatically tick box once the Leave Application created thru Blanket.
3. **From Balance** - the basis of the Leave Balance created for the particular employee and leave type.
4. **Company** - automated based on Employee's Company.

**f.** Upon completion of data, you may now save the Leave Application by clicking **Save**. The status will automatically update into **Pending**. On pending status the application was still allowed to edit or discontinue the application.


![](\docs\assets\img\employee_per_user\leave2.png)
![](\docs\assets\img\employee_per_user\leave3.png)


### **Overtime Application** ###


**a.** To create Overtime Application, select **Overtime Application** from Applications.

![](\docs\assets\img\employee_per_user\overtime.png)


**b.** To add new, click **New**.

![](\docs\assets\img\employee_per_user\overtime1.png)

**c.** To have new Application, you need to set up the following:

![](\docs\assets\img\employee_per_user\overtime2.png)

1. **Employee** - select employee name	.
2. **Is Previous** - this feature use for shift that crossing to the next day. Tick box if the application's target date will base on from date.
3. **Posting Date** - enter the date of overtime application posted.
4. **From** - enter the from date of the application.
5. **To** - enter end date of the application.
6. **From Time** - enter from time of the application. 
7. **To Time** - enter end time of the application.
8. **Break Hours** - enter break hours of the overtime application, this can be mandated base on timekeeping settings.
9. **Reason** - enter the reason of filing overtime application.
10. **Owner** - the one who created the application. (automated)

**d.** Upon completion of data, you may now save the Overtime Application by clicking **Save**. The status will automatically update into **Pending**. 

![](\docs\assets\img\employee_per_user\overtime3.png)
